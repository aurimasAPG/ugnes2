# 30-MINUTE BEAT SHEET — the slice against a stopwatch

Phase 4 requires this timed against ≥2 real sessions; the timings column stays empty
until then (a beat sheet with invented timings is worse than none). Beats derive from
the content dependency graph verified by `PlaythroughTests`.

| # | Beat | Intended window | Session A | Session B |
|---|---|---|---|---|
| 1 | Spawn at south gap; channel + kiln smoke + bridge visible in one frame | 0:00 | | |
| 2 | First interactable touched (sand / setting plate on the spine) | < 0:40 | | |
| 3 | Pip restless (eastward drift line) or first NPC talk | < 2:00 | | |
| 4 | First quest accepted (any of the three) | < 3:30 | | |
| 5 | First capability grant (Vesk's recipe family expected first) | 6:00–9:00 | | |
| 6 | Crafting panel first opened at the kiln | 7:00–10:00 | | |
| 7 | First climb to the shelf; vista notch moment | 9:00–13:00 | | |
| 8 | Scorched bark found → Quietday opens; world goes grey; ash starts | 10:00–15:00 | | |
| 9 | Second capability (Orrel's trade post or Coll's traversal) | 13:00–18:00 | | |
| 10 | Sluice puzzle solved (head gate at dawn); pool drains | 16:00–22:00 | | |
| 11 | Lower shelf entered; warm zone + ember light read | 18:00–24:00 | | |
| 12 | Second kiln found; mystery resolves; light returns | 21:00–27:00 | | |
| 13 | The unanswered question lands (final Pip/account beat) | 24:00–29:00 | | |

Watch for during the timed runs: beats arriving >5 min late (pacing), any beat skipped
entirely (routing), whether the tester notices the world going grey at beat 8 without
being told (the whole Quietday system's test), and whether beat 13 produces the
spontaneous question the Phase 4 gate demands.
