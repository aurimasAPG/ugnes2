# DERIVATIVENESS PASS 02 — the assembled look

Run 2026-08-08 against the M3–M7 build (screenshots: dawn village, day village).
Pass 01 deferred silhouettes and UI "until art exists"; generated art now exists.

## Assessed and cleared

- **Palette + atmosphere.** Desaturated wet-mineral world, warmth only in man-made
  light, overcast-neutral day. Traces to the world bible's own sentence, not to any
  property: deliberately away from Stardew/AC saturated-candy and from Zelda:BotW's
  painterly haze (no bloom, no god rays, no pastel gradient sky).
- **Character silhouettes.** Stocky-hooded, not chibi (head ≈ 0.46 m on ~1.7 m
  bodies, far from 1:2 chibi ratios); hoods not hats (no witch/farmhand read);
  differentiation is by build and prop (apron/ledger/gear), not palette-swap.
  No known property uses this trio-shape. CLEAR, re-check when faces/animation land.
- **Pip.** Moth silhouette with visible wing-beat, warm-white gutter, dims-not-
  highlights. The full anti-Navi package pass 01 demanded: not an orb, not blue,
  not a pointer. CLEAR.
- **Buildings.** Steep dark slate over stone bases — northern-European vernacular,
  generic by design. The kiln chimney and half-buried gear are industrial, which cuts
  against the cozy-farm read. CLEAR.
- **UI.** IMGUI boxes are pre-style; the decided Phase 4 spec (warm paper, ledger
  typography) must be re-passed when built — ledger-styling is period-generic but
  check against *Return of the Obra Dinn*'s notebook when implemented.

## Changed by this pass

- None required — the look was built from the bible's constraints, which pass 01
  already vetted.

## Referred / standing risks

1. **The title** — still open, still the largest IP exposure. See
   `docs/title-shortlist.md`.
2. **Quest-toast + sting pairing** is a universal pattern (fine), but the sting
   itself should be checked by ear against Zelda's discovery jingle once audio QA
   happens — a rising 3-note motif would be too close.
3. **The account screen** remains text-only; the no-corkboard/no-red-string
   constraint from pass 01 carries forward into Phase 4 UI work.
